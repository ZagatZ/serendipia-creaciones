# Carpeta de Recursos (Assets)

Esta carpeta está destinada a almacenar todos los recursos multimedia y estáticos del proyecto:

- `/images`: Fotografías, ilustraciones y logotipos (formatos `.svg`, `.webp`, `.png`, `.jpg`).
- `/icons`: Iconos del sistema o biblioteca SVG.
- `/fonts`: Tipografías personalizadas locales (en formato `.woff2`).
- `/docs`: Documentación descargable o archivos complementarios.
